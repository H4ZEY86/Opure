# Opure v0.1.0 - Founder Gate A Release

## The Zero-Trust Foundation

Opure v0.1.0 marks the successful completion of Founder Gate A, establishing the bedrock of our local-first, zero-trust architecture. This release delivers the foundational command and control layer for Windows 11, strictly adhering to the principle: **Build software with developers, not instead of them.**

### Core Deliverables

- **FND Constraints Enforcement**: Complete implementation of the FND baseline (FND-001 through FND-060). The Runtime operates entirely offline, starts without AI or remote capabilities, and establishes explicit boundary constraints around all authoritative state.
- **IPC Named Pipes Security Matrix**: Hardened inter-process communication between the Desktop and Runtime. Executed a 12-scenario matrix proving strict admission controls (32-connection ceiling), deterministic session authentication, and zero exposed TCP/UDP endpoints.
- **Fail-Closed Configuration Validation**: Delivered the Product Policy Evaluator with strict Base Profile enforcement. Executed a 19-scenario configuration adversarial matrix proving exact UTF-8 verification, duplicate key detection, unparseable input denial, and exact provenance tracking for all active settings.
- **Trust Evidence Forgery Defenses**: Established an immutable SQLite Persistence Library for Trust Evidence. Proved exact repair boundaries, hash-conflict quarantine, and isolated projection with a 15-scenario adversarial forgery and reconciliation suite.
- **Accessibility and Performance Verification**: Passed Windows 11 Desktop accessibility baselines and bounded latency constraints for authenticated shell interactions.

### Dual-Mode Architecture (Full-Stack Release)

This release upgrades the initial headless Gate A build into a complete **Full-Stack Synchronized Platform**. It introduces the unified deployment orchestration, packaging the core Daemon CLI and the MSIX Desktop App together.

- **MSIX Desktop App Sync**: The Avalonia-based Desktop UI is now fully wired up to the headless Runtime engine using authenticated named-pipe IPC. The Desktop shell correctly visualizes the local Trust Centre, Project list, and Offline configuration state.
- **Offline Ed25519 License Verification**: Delivered the Open Core monetization enforcement. The system now securely validates offline Ed25519 license keys natively. Both the `opure license apply` CLI command and the new "Opure Pro" Desktop UI tab synchronize seamlessly, persisting state into the shared local app data without requiring active network endpoints.
- **Unified Deployment Orchestration**: A streamlined installation pipeline guarantees correct provisioning of the self-signed developer certificates, the `runFullTrust` MSIX bundle, and the headless daemon routing aliases in a single package.

### Quality and Verification
Every component is backed by exact, repeatable test verifications. The Founder Gate A release encompasses **800 verified tests** passing with absolute stability: 0 warnings and 0 errors under the `Release` build configuration, as certified by the automated build policy and exact Git versioning.
