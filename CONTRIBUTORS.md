# Contributors

The sole recognised contributors and maintainers of Opure are:

- H4ZEY86
- DevMediaDesign

Repository, package, release and documentation attribution must use these names.
Automated tools, editors, assistants, bots and generated checkpoint identities
must not be credited as contributors.

Historical aliases belonging to a recognised maintainer are normalised through
the repository `.mailmap`. Published commit objects remain immutable; the
mailmap changes their presentation without rewriting or falsifying history.

New contribution attribution requires explicit approval from the maintainers
and an update to this file.
