# CM-003: Validate Workspace Boundary and Source Preconditions

## Implementation Summary
- **Component**: `Opure.Workspace.Boundaries.WorkspacePreconditionValidator`
- **Objective**: Implement strict, zero-trust file validation to guarantee absolute file path and state integrity before mutation.

## Architectural Defenses & Verification
- **TOCTOU File-Locking**: Implemented an atomic Time-Of-Check to Time-Of-Use defense. `WorkspacePreconditionValidator` opens the target file exclusively with `FileShare.Read | FileShare.Delete` and immediately resolves attributes and the SHA-256 hash using the locked `FileStream`. This prevents concurrent modification and directory swapping after the validation lock.
- **Strict Case and Unicode Collision Rejection**: Defeated NTFS aliasing attacks by explicitly verifying requested components against `DirectoryInfo.GetFileSystemInfos()` to reject Form C vs Form D normalization collisions and casing collisions.
- **Reserved Device Path Block**: Hardened against Windows namespace injection by blocking all MS-DOS reserved device names (CON, NUL, COM1-9, LPT1-9, PRN, AUX) natively and at every directory component, regardless of extension spoofing.
- **Symlink/Junction Escapes**: Added dynamic privilege-aware tests and blocked path traversal outside of the trusted `CanonicalPath` Workspace Root, safely inspecting `ReparsePoint` flags post-lock.
- **Source Drift Detection**: Computes expected vs actual length and SHA-256 hash securely, strictly failing closed.
